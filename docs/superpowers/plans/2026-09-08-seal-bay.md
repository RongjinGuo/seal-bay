# Seal Bay Implementation Plan

> Execute within this task using independently scoped agents; integrate and visually verify each artifact.

**Goal:** Deliver a polished playable touch-first seal feeding game with original Blender models and researched seal calls.

**Architecture:** A Vite/Three.js browser application loads Blender-exported seal variants. Pure simulation functions own gestures and lifecycle. The app coordinates models, water effects, audio and Chinese HUD.

**Tech Stack:** Blender Python, glTF, Three.js, Vite, Web Audio, Node test runner, browser automation.
